# Exact-text substitutions applied to the port's source mirror by
# port/tools/mirror_src.py.  The decomp's own files are never edited.
#
#   [target:]relative/path<TAB>old text<TAB>new text
#
# `\n` and `\t` are unescaped in both texts.  Each patch must match its file
# exactly once or the build fails, so an upstream edit that moves the text is
# a loud error rather than a silent no-op.  `host:` / `ppc:` restricts a patch
# to one target.
#
# Metrowerks `asm { }` blocks and whole-function `asm` definitions are removed
# by the mirror itself, not from here -- see mirror_src.py step 2.

# `__OSBusClock` and `__OSCoreClock` are *tentative definitions* here -- on the
# console they are fixed addresses in low memory, so the header declares them
# rather than externs them.  Off the console, and built with -fno-common, every
# translation unit that includes <dolphin/os.h> gets a real definition, and a
# REL bundle therefore links its OWN zero-valued copy instead of binding to the
# port's.  That is not a small error: OS_TIMER_CLOCK is OS_BUS_CLOCK / 4, so
# inside all 99 modules
#
#     OSTicksToMilliseconds(x) == (x) / (OS_TIMER_CLOCK / 1000) == x / 0
#
# and PowerPC integer division by zero does not trap -- it quietly yields
# garbage.  `bootDll` paces the Nintendo logo with
# `while (OSTicksToMilliseconds(OSGetTick() - t0) < 3000) HuPrcVSleep();`, so
# the boot sat on the logo for as long as you cared to watch, at a healthy

#
#     s16 unk_0C[4];

#     s16 unk_16;

#
# 0x0C + 4*2 == 0x14 and 0x0C + 5*2 == 0x16, so `unk_14` and `unk_16` *are*

# to 6 (score.c:71, 138, 151), which is the six digits/labels of the score
# readout.  Merging the three declarations moves nothing: the array still

# the decompiler's: `fn_1_91D8` runs `var_r31 < 7` over six handles, so the
# seventh `espKill` is handed the top half-word of `unk_18` -- an `s32` flag
