# Every function in the decomp that falls off the end of a non-void body.
#
# Metrowerks left the last value that happened to be in r3 there, and a
# decomp that matches its output therefore has functions with no `return`
# whose callers still read a useful number.  GCC 14 does not: it returns
# whatever the last call left in r3, or a tail call's result.  The build
# turns the diagnostic off (`GAME_WARN` is `-w ... -Wno-return-mismatch`),
# so none of this is visible in a normal build.
#
# Produced 2026-09-17 (M12) by compiling every mirrored translation unit with
# -Wreturn-type.  -fsyntax-only does NOT report this class: the diagnostic is
# emitted by the CFG pass, so the audit has to be a real compile.
#
#   for f in port/build-ppc-darwin/gen/src/**/*.c; do
#       powerpc-apple-darwin8-gcc <GAME_CFLAGS minus -w> -Wreturn-type -c -o /dev/null $f
#   done
#
# One of these was a real, reproduced hang: mstory3Dll/result.c's fn_1_16924
# (line 375 here) is the board-result prompt that no button could answer and
# that stopped every soak from chaining a second board.  See PLAN.md 26.1 and
# the patch in port/patches.txt.  The other 42 are unaudited: a caller that
# ignores the value is harmless, a caller that tests it is a bug waiting.
#
