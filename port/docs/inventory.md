# Mario Party 4 -- SDK and GX inventory

Generated by `port/tools/inventory.py`. Re-run after any upstream merge:

```sh
python3 port/tools/inventory.py
```

Counts are lexical: a regex over comment-stripped, string-stripped C source.
They count *sites*, not dynamic calls, and they include sites inside
`#if VERSION_*` blocks for versions we do not build. `sdk/*` rows include the
SDK's own definitions and internal calls, so read them as "how much code is
there", not "how much the game asks for".
